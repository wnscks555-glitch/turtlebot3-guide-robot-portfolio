# TurtleBot3 안내로봇 프로젝트

2022.03~2022.06 진행한 안내로봇 제작 팀 프로젝트입니다.
Raspberry Pi, OpenCR, LiDAR, 모터, 터치스크린을 통합했습니다.

## 본인 역할
- 하드웨어 조립 지원
- Ubuntu·ROS 환경 재설치 확인 참여
- 발표자료 작성 및 발표

## 진행 결과
- 팀에서 A/S 후 2모터 구동과 약식 맵핑 확인
- 최종 4모터 구성에서는 속도 명령 출력까지 확인했으나 실차 구동은 미완료
- 제작 과정과 미동작 문제의 점검 결과를 발표자료로 정리
